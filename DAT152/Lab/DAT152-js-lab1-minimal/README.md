# DAT152 JavaScript Lab 1 - minimalt startprosjekt

Dette prosjektet inneholder bare det som trengs for å kjøre oppgavene lokalt.
Oppgave 1-3 er ikke løst, og HTML-innholdet du trenger i hver oppgave er heller ikke laget.

## Starte i IntelliJ

1. Åpne denne mappen med **File > Open**.
2. Åpne terminalen i IntelliJ.
3. Kjør:

   ```bash
   npm start
   ```

4. Gå til <http://127.0.0.1:5500>.

Du trenger Node.js 18 eller nyere, men trenger ikke kjøre `npm install`.

## Filer du skal arbeide i

- `public/task1/index.html`
- `public/task1/task1.js`
- `public/task2/index.html`
- `public/task2/task2.js`
- `public/task3/index.html`
- `public/task3/task3.js`

`index.html` i prosjektets `public`-mappe er bare en enkel meny mellom oppgavene.

Oppgave 4 krever `apitemplate.zip` fra Canvas og er derfor ikke satt opp her.

## Generelle tips

- Lagre filen og oppdater nettleseren etter endringer.
- Åpne utviklerverktøy med `F12` og se i **Console** ved feil.
- Kjør `npm run check` for å finne syntaksfeil i JavaScript-filene.
